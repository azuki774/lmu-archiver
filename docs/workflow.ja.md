# ワークフロー

[English](workflow.md)

## 対象範囲と前提条件

現在の Go 実装は、起動中の Le Mans Ultimate（LMU）から Steam セッション
チケットを取得し、オンラインバックエンドで認証するところまでを対象とします。
具体的なデータ取得・加工・保存は別途実装します。ここでは、戦績取得の
エンドポイントや保存形式は決めません。

対象のデータを所有する Steam アカウントで LMU を起動し、メインメニューまで
進めてください。アーカイバから LMU PC のローカル REST API に接続できる必要が
あります。接続先 URL（ホストとポート）は `--lmu-url` で指定します。CLI の既定値は
`http://127.0.0.1:16397` です。実行中の LMU が待受しているポートを指定してください。
参照実装の例とは異なる場合があります。同じプロセスから `https://raceos.gg` へ、
プロキシを介さず直接接続できる必要もあります。

## 1. LMU のセッションチケットを取得する

```http
GET http://<Le Mans Ultimate PC>:<port>/rest/profile/getAuthSessionTicket
Accept: application/json
```

JSON レスポンスの文字列 `authSessionTicket` を読み取ります。
リクエストに失敗した場合や、チケットが欠落・空文字・空白のみの場合は処理を
中止し、バックエンドの認証リクエストは送信しません。

ローカル API は平文 HTTP です。信頼できるネットワーク内でのみ利用し、
インターネットに公開しないでください。

## 2. オンラインバックエンドで認証する

認証先は **RaceOS（`raceos.gg`）** です。
[LMU Central の認証実装](https://github.com/MarteauPiqueurdu11/LMU-Central/blob/main/lmu_central/core/raceos.py)
に合わせ、`https://raceos.gg/authenticate` にのみチケットを送信します。
参照先は第三者による実装であり、公式 API 仕様でも実行時の依存先でもありません。

```http
POST https://raceos.gg/authenticate
Accept: application/json
Content-Type: application/json

{"token":"<authSessionTicket>","game":"lmu","platform":"steam"}
```

JSON レスポンスの文字列 `accessToken` を Go の `auth.Session` に保持します。
トークンが欠落・空文字・空白のみの場合は処理を中止します。
トークンの有効期間は仮定せず、認証情報のディスクキャッシュや自動更新も
実装しません。新しいセッションが必要な場合は、LMU の起動中に再度認証します。

CLI は上記の2リクエストを逐次実行し、間に1.2秒待機します。
各リクエストのタイムアウトは20秒です。自動リトライ、リダイレクト追従、
環境変数のプロキシ設定は使いません。HTTPS の証明書検証は有効です。
HTTP エラーや不正なレスポンスを受け取った場合は処理を中止し、
レスポンス本文・チケット・アクセストークンを出力しません。
キャンセル時は進行中のリクエストと、リクエスト間の待機を中止します。

## 3. 認証情報に基づいてデータを取得・加工・保存する（後続の実装）

データ取得は未実装です。追加するときは、返されたセッションを同じプロセス内で
保持し、後続のバックエンドへのリクエストでは、参照実装に合わせて次のヘッダで
アクセストークンを渡します。

```http
Game-Authorization: Bearer <accessToken>
```

想定する後続処理は次のとおりです。

1. 認証済みセッションを使い、必要なデータを取得する。
2. アーカイバ用に決めた表現へデータを加工する。
3. ユーザが管理する保存先へ保存する。

エンドポイント、データモデル、加工方法、保存先、ファイル形式は意図的に未決定です。
現在の `auth` コマンドはデータ取得リクエストを送信せず、レースデータの加工や
アーカイブの書き込みも行いません。`Authentication succeeded.` のみを表示し、
終了時にメモリ内のセッションを破棄します。接続・認証確認用のコマンドであり、
次回の実行に向けたログイン情報の永続化ではありません。

## 実行方法

```sh
make build
./bin/lmu-archiver auth --lmu-url http://192.0.2.10:16397
```

例のアドレスを LMU PC のアドレスに置き換えてください。
第三者のコンパニオンアプリの導入は不要です。
Steam チケットとアクセストークンは秘密情報として扱い、ログ出力・表示・永続化を
しないでください。本プロジェクトから第三者のダッシュボードやストレージへの
データ同期は行いません。
