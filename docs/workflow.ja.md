# ワークフロー

[English](workflow.md)

1. **LMU からセッションチケットを取得する。**
   起動中の Le Mans Ultimate から認証用のチケットを取得する。
2. **raceos.gg で認証する。**
   チケットを使い、レースデータへのアクセスに必要な認証情報を取得する。
3. **データを取得・加工・保存する。**
   その認証情報を使って必要なデータを取得し、アーカイブ用に加工して、
   ユーザが管理する保存先へ保存する。

現在はチケット取得・認証に加え、現在のレーティング観測、
取得済み結果JSONのSQLite取り込み・検索まで実装している。
生の結果JSONは別ファイルとし、DBには自分の情報を正規化して保存する。
参考レートは、イベント日時以前の最新観測値を検索時に選ぶ。
結果APIからの自動取得は未実装。

詳細は [SQLite設計と運用](storage.ja.md) を参照。
