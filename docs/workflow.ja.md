# ワークフロー

[English](workflow.md)

1. **LMU からセッションチケットを取得する。**
   起動中の Le Mans Ultimate から認証用のチケットを取得する。
2. **raceos.gg で認証する。**
   チケットを使い、レースデータへのアクセスに必要な認証情報を取得する。
3. **データを取得・加工・保存する。**
   その認証情報を使って必要なデータを取得し、アーカイブ用に加工して、
   ユーザが管理する保存先へ保存する。

現在の実装範囲は、チケット取得と認証まで。
具体的なデータ取得・加工・保存は別途実装する。

## API 呼び出しの間隔

CLI は LMU・RaceOS 共通の HTTP クライアントを使い、前の通信で
レスポンスヘッダーを受信するか通信エラーになってから、次の送信まで最低1秒空ける。
並列呼び出しも同じ制限を共有し、待機中のキャンセルに対応する。
認証途中の既存の1.2秒待機は維持する。自動リトライは行わない。
待機時間も20秒のリクエストタイムアウトに含む。
別プロセスの同時起動や transport 内部の再送、サーバーへの到着間隔は保証対象外。
